# Invitation typography

Alibaba PuHuiTi 2.0 Regular, Medium and SemiBold match the font faces specified in
the invitation dialog and share-card Figma nodes. The original Version 2.00 TTFs
come from Alibaba's official distribution:

https://ics-static.oss-cn-hangzhou.aliyuncs.com/static/ucan/Alibaba_PuHuiTi2.0.zip

The WOFF2 files and Unicode ranges come directly from the publisher's official
web-font distribution, also linked by https://fonts.alibabagroup.com/:

https://fonts.alibabadesign.com/AlibabaPuHuiTi-2/

The font binaries are unmodified. The CSS uses the shared display family name and
the design's corresponding weight. The publisher's unmodified legal statement is
included as `LICENSE.pdf`. Unicode ranges load only the needed characters when
used by invitation content and do not change the application's default font.
